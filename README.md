# SkyTech Simulator for Unity

本格的なアルペンスキー・レーシングマシンの挙動を再現する、Unity向けの2リンク・バイオメカニクス物理シミュレータです。  
雪面グリップ物理、エッジ貫入、下肢の筋張力モデル、股関節外傾/内倒ダイナミクスを忠実に計算し、**「iPhoneの画面傾き（下肢エッジング）」×「AirPodsの頭部ヘッドトラッキング（体幹傾き）」によるデュアルセンサー操縦**に対応しています。

---

## 🌟 主な特徴

- **2リンク生体力学シミュレーション (`SkyTechPhysicsSolver`)**
  - 下肢リンク（脚長 $l_1$, ロール角 $	heta_1$）と体幹リンク（上体長 $l_2$, ロール角 $	heta_2$）の連立運動方程式。
  - ヒルの力-速度関係式（Hill's Muscle Model）に基づく下肢筋力・無酸素スタミナ消費。
  - 人体解剖学に基づく股関節可動域制限と、72°〜80°でのストレート内倒自動移行制御。
- **雪面エッジ貫入 & グリップ物理**
  - 雪面硬度 $K_{\text{snow}}$ と有効エッジ長、法線押付力によるリアルタイムエッジ貫入深さ（mm）の算出。
  - Modified Howeフレックスカーブによる横G計算。雪面せん断破壊時のスキッディング（ズレ）移行。
  - カービング、抜重、ズレ、レール衝突、ブーツアウト、腰落ち転倒などの状態判定。
- **iPhone × AirPods デュアルセンサー操縦**
  - **iPhone 端末チルト**: 画面の傾き（加速度/ジャイロ）で下肢ロール（エッジ角 $	heta_1$）をダイレクト操作。
  - **AirPods ヘッドトラッキング**: `CMHeadphoneMotionManager` を使用し、首のかしげ角度で上体（体幹絶対角 $	heta_2$）を独立制御。
  - ストレート内倒を超えた過度な内倒（オーバーリーンイン）を検出した際の**ハプティクス（振動）＆画面警告**。
- **プロ仕様のHUD・テレメトリ視覚化 (`SkyTechVisualizer`)**
  - 理想のターン弧・リズムを誘導する「ペースメーカー（Ideal Mouse Lead Marker）」。
  - デュアルチルト水平ゲージ、2リンク骨格線、重心（CoM）ベクトルのリアルタイム描画。
  - ワールドカップ基準のターン評価＆コンボスコアシステム。

## 📦 インストール & セットアップ手順

### 1. Unity プロジェクトへの導入
1. 本リポジトリのスクリプト群を Unity プロジェクトの `Assets/Scripts/SkyTechSimulator/` フォルダへ配置します。
   - `SkyTechPhysicsSolver.cs`
   - `SkyTechSimConfig.cs`
   - `SkyTechGameController.cs`
   - `SkyTechVisualizer.cs`
   - `AirPodsMotionManager.cs`
2. **iOS用ネイティブブリッジ（AirPods実機利用時のみ）**
   - iOS実機でAirPodsモーションを取得する場合、`Assets/Plugins/iOS/HeadphoneMotionBridge.mm`（CoreMotionの `CMHeadphoneMotionManager` を呼び出すObjective-C++プラグイン）を配置してください。

### 2. シーンのセットアップ
- **自動セットアップ**:  
  空の新規シーンを作成して「再生（Play）」ボタンを押すだけで、`[RuntimeInitializeOnLoadMethod]` により自動的に `SkyTechSimulator` オブジェクトとカメラが初期化・生成されます。
- **手動セットアップ**:
  1. シーン内に空の GameObject を作成し、名前を `SkyTechSimulator` に変更。
  2. `SkyTechGameController` コンポーネントを追加。
  3. `SkyTechVisualizer` コンポーネントを追加（自動的にコントローラと連携）。
  4. Projectウィンドウで右クリック → `Create > SkyTech > SimConfig` を選択して設定アセット `SkyTechSimConfig.asset` を作成し、`SkyTechGameController` の **Config** スロットへアサイン。

### 3. iOS向けビルド設定（AirPods / 端末チルト）
1. `File > Build Settings` で Platform を **iOS** に切り替えます。
2. `Player Settings > Other Settings`:
   - **Accelerometer Frequency**: 60Hz 推奨
   - **Motion Usage Description**: 「スキーシミュレータの頭部傾き姿勢制御に使用します」などの説明文を入力
3. Xcodeでビルド後、iOS実機に転送して実行します。

## 🎮 操作方法 (Controls)

本シミュレータは、**「PC / Unityエディタ（マウス＋キーボード）」** と **「iOS実機（iPhone傾き＋AirPods）」** の双方で快適にプレイ可能です。

### 1. PC / Unityエディタでの操作

| 入力デバイス | 操作内容 | 挙動 |
| :--- | :--- | :--- |
| **マウス 左右移動** | ステア / 脚ロール ($	heta_1$) | 左右に大きく振ることで下肢を雪面へ倒し込みます（S字感度緩和付き）。 |
| **マウス 上方向** | 脚伸展 ＆ リーンイン | **CENTER**基準線より上で脚が伸び、**LEAN-IN LINE**を超えるとストレート内倒、**STRAIGHT LINE**を超えると逆くの字内倒へ移行します。 |
| **マウス 下方向** | リーンアウト（外傾） | 脚を曲げずに上体をターン外側へ屈曲させ、外傾姿勢を作ります。 |
| **A / D** または **← / →** | デジタルステア | キーボードでの左右ステア・エッジング。 |
| **Space** / **↑** | 脚伸展 (Extension) | 脚を力強く伸ばして雪面を踏み込みます（Gを耐える）。 |
| **S** | 脚屈曲 (Flexion) | 膝を曲げて抱え込み、抜重（アンウェイト）します。 |
| **Q / E** | AirPods傾きシミュレート | 頭部・体幹目標角（$	heta_2$）を左右に傾けます（キーを離すと緩やかに直立復帰）。 |
| **W** / **X** | 直立リセット | 一時的に直立ニュートラル姿勢へ強制復帰。 |
| **C** | ゼロ点補正 | センサーおよび現在姿勢のキャリブレーション。 |
| **R** | シミュレーションリセット | 位置・速度・スタミナを初期状態にリセット。 |
| **Tab** | オートアシスト切替 | 外傾自動アシストのON/OFF。 |

### 2. iOS実機 + AirPods での操作（推奨）

iPhoneを両手で水平に持ち、AirPodsを装着してスキーヤーのスタンスをとります。

1. **画面の左右チルト（iPhoneを傾ける）**:
   - スキーの板・脚のロール角 $	heta_1$（エッジ角）を直接コントロール。
   - 傾けるほど深く鋭角に雪面を捉えます。
2. **頭の傾き（AirPodsで首をかしげる）**:
   - 上体・体幹のロール角 $	heta_2$ を独立コントロール。
   - **ターン外側に首をかしげる**: 強い外傾（アンギュレーション）が生まれ、高負荷Gに耐えます。
   - **顔をまっすぐ鉛直に保つ**: 安定したナチュラル外傾を維持。
   - **ターン内側に首を倒しすぎる**: ストレート内倒限界を超えると「**OVER LEAN-IN WARNING**」が発動し、端末が振動して警告します。
3. **キャリブレーション**:
   - 画面上部ゲージの **「ゼロ点補正」** ボタンをタップすると、その瞬間のiPhone傾きと頭の向きが「中立（0°）」としてリセットされます。

## 📊 画面UIとテレメトリの見方

```
+-----------------------------------------------------------------------------------+
|  [BIOMECHANICS & TELEMETRY]                    [ ▲ OVER LEAN-IN WARNING! ]         |
|  - GRIP: CARVING / SKIDDING                    [ 📱 iPhone Tilt  🎧 AirPods ]      |
|  - Edge θ1 vs CoM Ψ                             +------[====|====]------+         |
|  - Hip φ / CoM Shift                                  デュアルチルト水平ゲージ        |
|  - Leg Power / Stamina                                                            |
|                                                      [TURN SCORE & COMBO]         |
|                                                      - Score: 12,450              |
|                     ( 理想のマウスリード軌道 〇 )             - Peak: 68.5°               |
|                           ＼                         - "WORLD CUP CARVE!!"        |
|                  STRAIGHT LINE -----------------------                            |
|                  LEAN-IN LINE  -----------------------                            |
|                  CENTER LINE   ======= 人体2リンク ======                           |
|                  FLEX / OUT    -----------------------                            |
|                                                                                   |
|  ===============================[ レール台車 ]==================================   |
+-----------------------------------------------------------------------------------+
```

1. **デュアルチルト水平ゲージ（画面上部）**
   - **青い縦バー**: iPhoneの傾き（脚ロール角 $	heta_1$ / ストレート内倒境界）。
   - **黄色/緑の丸マーカー**: AirPodsの頭部角（体幹角 $	heta_2$）。
   - **ブリッジ帯**: 股関節外傾角 $\phi$。内倒しすぎると帯が赤くなり警告を発します。
2. **画面中央の誘導ライン（Crosshair Guide）**
   - **STRAIGHT LINE**: 脚と上体が完全に一直線（$\phi = 0$）になる基準線。
   - **LEAN-IN LINE**: 外傾維持からストレート内倒へ移行を開始する境界線。
   - **CENTER**: 標準スタンスの中立線。
   - **FLEX / LEAN-OUT**: リーンアウト（外傾）下限線。
3. **ペースメーカー（Ideal Mouse Lead Marker）**
   - 画面上を自動周回するグリーンのパルスリング。
   - レール幅の70%を活用し、**目標エッジ角70°の極限ディープカービング**を刻むための理想的なストローク・リズムを示します。
4. **グリップ状態インジケータ**
   - `CARVING`: 理想的なエッジ噛み込み状態（緑）。
   - `UNWEIGHTED`: 切り返し等の無荷重・抜重状態（黄）。
   - `SKIDDING`: 雪面耐力を超過してエッジが外れたズレ状態（赤）。
   - `BOOT OUT` / `HIP CRASH`: バランス崩壊・腰落ちによる転倒クラッシュ。

## ⚙️ パラメータ設定 (`SkyTechSimConfig`)

Inspector上の `SkyTechSimConfig` アセットから、雪質やマシン設定を自由に変更可能です。

| グループ | 主なパラメータ | 説明 |
| :--- | :--- | :--- |
| **Environment** | `W_rail` (17.2m) | マシンのレール全幅。左右のストローク限界を決定。 |
| | `mu_snow` (0.04) | 雪面の摩擦係数。 |
| **Modified Howe** | `G0_curve` (2.60) | 遠心力発生ベース係数。 |
| | `V_ref` (14.5 m/s) | 基準滑走速度（約52 km/h）。 |
| **Snow & Grip** | `snowHardnessK` (500,000) | 雪の硬さ (Pa)。アイスバーンは `900,000`、軟雪は `250,000`。 |
| | `effectiveEdgeLength` (1.48m) | スキー板の実効エッジ長。 |
| | `theta_bootOutDeg` (90.0°) | ブーツアウト転倒角度。 |
| **Biomechanics** | `F_ext_max_G` (3.8G) | 下肢最大等尺性伸展筋力。 |
| | `maxStamina` (1800 J) | 無酸素スタミナ容量。高負荷ターンを連続すると疲労します。 |
| | `phi_out_maxDeg` (48.0°) | 股関節の最大外傾角度。 |

## 💡 上達のコツ (How to Master)

1. **切り返し（ターン始動）**:
   - 切り替えポイントでは一度脚の力を抜き（抜重）、iPhone / マウスをスムーズに反対側へ切り替えます。
2. **捉え〜フォールライン（加圧）**:
   - エッジ角が深まるにつれて下肢を力強く伸展（Spaceキーまたは上方向）させ、遠心Gに耐えます。
3. **外傾のキープ**:
   - ターン前半〜中盤は顔を直立〜やや外側に保ち、しっかり外傾を作ってエッジを食い込ませます。
4. **極限のディープターン（70°超）**:
   - 72°を超えると物理ソルバーが自動的に「ストレート内倒」へ移行し、破綻を防ぎます。ペースメーカーのリングを追いかけるようにリズミカルに滑りましょう！
